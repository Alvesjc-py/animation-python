# animation-python 🖥️

Esse projeto é um script simples em **Python** que cria um efeito de **digitação estilo “PC antigo”**, exibindo o conteúdo letra por letra no terminal.

Ele imprime um **desenho em ASCII ART** e depois a palavra **"teste"**, simulando o efeito de código sendo digitado em tempo real.
